# Sprint 5 – Flow Designer & Workflow Automation

## Overview

Sprint 5 focused on introducing **Flow Designer automation** to JobFlow, reducing manual effort and improving data consistency throughout the job application lifecycle.

Instead of relying on manual updates, the application now automatically creates interview records and synchronizes application statuses based on interview outcomes.

---

## Objectives

- Learn and implement ServiceNow Flow Designer.
- Automate repetitive user tasks.
- Maintain data consistency between related tables.
- Keep the application low-code and maintainable.
- Demonstrate practical workflow automation for a real-world use case.

---

## Flow 1 – JF - Auto Create Interview

### Business Requirement

Whenever a Job Application progresses to the **Interview Scheduled** stage, the user should not have to manually create an Interview record.

### Automation

When:

- Job Application Status changes to **Interview Scheduled**

Automatically:

- Creates a new Interview record.
- Links the Interview to the corresponding Job Application.

### Business Value

- Eliminates repetitive manual work.
- Ensures every scheduled interview has a corresponding Interview record.
- Maintains referential integrity between Job Applications and Interviews.

### ServiceNow Concepts Used

- Flow Designer
- Record Updated Trigger
- Create Record Action
- Reference Field Mapping

---

## Flow 2 – JF - Synchronize Interview Result

### Business Requirement

After completing an interview, users often update both:

- Interview Result
- Job Application Status

This duplicates effort and can lead to inconsistent data.

### Automation

When:

- Interview Result is updated

Automatically updates the related Job Application.

Current mappings:

| Interview Result | Job Application Status |
|------------------|------------------------|
| Selected | Offer Received |
| Rejected | Rejected |

### Business Value

- Eliminates duplicate updates.
- Maintains consistency between Interview and Job Application records.
- Improves reporting accuracy.
- Reduces user errors.

### ServiceNow Concepts Used

- Flow Designer
- Conditional Logic (If / Else If)
- Update Record Action
- Reference Field Updates
