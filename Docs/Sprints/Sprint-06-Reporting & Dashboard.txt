# Sprint 6 – Reports & Dashboard

## Overview

Sprint 6 focused on enhancing the JobFlow application with reporting and analytics capabilities. The objective was to transform the application from a functional job tracker into a data-driven platform that provides meaningful insights into the job application process.

Using ServiceNow's reporting engine and dashboard capabilities, several reports were created to visualize application progress, company distribution, interview outcomes, and other key metrics. These reports were then consolidated into a centralized dashboard for quick access.

---

## Business Requirement

As the number of job applications increases, manually reviewing records becomes inefficient. A dashboard provides an at-a-glance overview of the job search pipeline, helping users answer questions such as:

- How many applications have been submitted?
- Which companies have received the most applications?
- What is the current application status distribution?
- What interview outcomes have been recorded?
- What applications require immediate attention?

This feature demonstrates how ServiceNow can be used not only for process automation but also for operational reporting and business intelligence.

---

## Features Implemented

### Reporting

Created custom reports for the JobFlow application:

- Applications by Status (Pie Chart)
- Applications by Company (Bar Chart)
- Applications by Employment Type (Pie Chart)
- Applications by Source (Pie Chart)

These reports utilize ServiceNow's built-in reporting engine and dynamically update as new records are added.

---

### Dashboard

Created a centralized dashboard:

**Dashboard Name**

```
JobFlow Dashboard
```

The dashboard consolidates all JobFlow reports into a single workspace, allowing users to monitor their job search progress without navigating through individual lists.
