# JobFlow

> A ServiceNow-based Career Relationship Management (CRM) platform designed to help job seekers manage companies, recruiters, job applications, interviews, follow-ups, and career progress.

---

## Overview

JobFlow is a personal portfolio project built on the ServiceNow platform.

The objective is twofold:

- Build a real-world ServiceNow application following enterprise development practices.
- Use the application daily to manage and streamline my own software job search.

Rather than being a demonstration project, JobFlow is intended to evolve into a production-style application with automation, reporting, security, and workflow capabilities.
